# Техническое задание: FilaTrack — Учёт филамента для 3D-принтера

## 1. Общее описание

**FilaTrack** — десктопное приложение на Go с GTK-интерфейсом для учёта расхода филамента 3D-принтера. Приложение позволяет парсить G-code файлы, отслеживать успешные и неудачные печати, управлять запасами филамента и контролировать циклы сушки.

## 2. Технологический стек

|-----------------|---------------------------------------------------------------|

| Тестирование    | стандартный `testing` + [testify](https://github.com/stretchr/testify) |

## 3. Функциональные требования

### 3.1. Управление филаментом (Spool Management)

- **FR-1.1** Добавление нового филамента (производитель, материал, цвет, диаметр, вес нетто, цена).
- **FR-1.2** Просмотр списка филаментов с фильтрацией по материалу, цвету, производителю.
- **FR-1.3** Отображение остатка филамента (вес и процент) с учётом всех печатей.
- **FR-1.4** Редактирование и архивирование (мягкое удаление) катушек.
- **FR-1.5** Поддержка материалов: PLA, PETG, ABS, ASA, TPU, Nylon, PC, и пользовательские.

### 3.2. Парсинг G-code

- **FR-2.1** Импорт `.gcode` файлов с извлечением метаданных:
  - Расчётный расход филамента (длина в мм и вес в граммах).
  - Расчётное время печати.
  - Температуры (сопло, стол).
  - Имя модели, слайсер, профиль.
- **FR-2.2** Поддержка комментариев слайсеров: PrusaSlicer, Cura, OrcaSlicer, BambuStudio.
- **FR-2.3** Расчёт веса по длине филамента с учётом диаметра и плотности материала.

### 3.3. Учёт печатей (Print Log)

- **FR-3.1** Создание записи о печати с привязкой к катушке и G-code файлу.
- **FR-3.2** Статусы печати:
  - `success` — успешная печать, расход списывается полностью по G-code.
  - `failed` — неудачная печать, пользователь указывает процент выполнения (0–100%), расход рассчитывается пропорционально.
  - `cancelled` — отменена пользователем, аналогично `failed`.
- **FR-3.3** Автоматическое списание филамента с катушки при сохранении записи.
- **FR-3.4** Просмотр истории печатей с фильтрацией по статусу, катушке, дате.
- **FR-3.5** Статистика: общий расход, процент успешных печатей, средний расход на печать.

### 3.4. Учёт сушки (Drying Log)

- **FR-4.1** Создание записи о сушке: катушка, температура, длительность, дата.
- **FR-4.2** Рекомендации по сушке в зависимости от типа материала (предустановленные профили).
- **FR-4.3** Отслеживание времени с последней сушки для каждой катушки.
- **FR-4.4** Уведомление (визуальный индикатор), если катушка не сушилась дольше рекомендованного периода.

### 3.5. Статистика и отчёты

- **FR-5.1** Дашборд: общий расход филамента, количество печатей, процент успеха.
- **FR-5.2** Расход по материалам и производителям (графики/таблицы).
- **FR-5.3** Расход за период (неделя, месяц, произвольный диапазон).

## 4. Нефункциональные требования

- **NFR-1** Кроссплатформенность: Linux, macOS (GTK4 доступен через Homebrew).
- **NFR-2** Данные хранятся локально в SQLite-файле.
- **NFR-3** Время парсинга G-code файла до 100 МБ — не более 5 секунд.
- **NFR-4** Приложение не требует сетевого подключения.
- **NFR-5** Чистая архитектура: разделение на слои (domain, repository, service, ui).

## 5. Модель данных

### Spool (Катушка)

| Поле           | Тип       | Описание                          |
|----------------|-----------|-----------------------------------|
| id             | UUID      | Уникальный идентификатор          |
| manufacturer   | string    | Производитель                     |
| material       | string    | Тип материала (PLA, PETG, ...)    |
| color          | string    | Цвет                              |
| color_hex      | string    | HEX-код цвета для отображения     |
| diameter_mm    | float64   | Диаметр филамента (1.75 / 2.85)   |
| total_weight_g | float64   | Начальный вес нетто (г)           |
| price          | float64   | Цена за катушку                   |
| density_g_cm3  | float64   | Плотность материала (г/см³)       |
| purchased_at   | timestamp | Дата покупки                      |
| archived       | bool      | Архивирована                      |
| created_at     | timestamp | Дата создания записи              |
| updated_at     | timestamp | Дата обновления                   |

### PrintJob (Печать)

| Поле                | Тип       | Описание                              |
|---------------------|-----------|---------------------------------------|
| id                  | UUID      | Уникальный идентификатор              |
| spool_id            | UUID      | FK на катушку                         |
| gcode_filename      | string    | Имя файла G-code                      |
| model_name          | string    | Название модели                       |
| status              | enum      | success / failed / cancelled          |
| completion_percent  | int       | Процент выполнения (0–100)            |
| estimated_weight_g  | float64   | Расчётный расход по G-code (г)        |
| actual_weight_g     | float64   | Фактический расход (с учётом %)       |
| estimated_length_mm | float64   | Расчётная длина филамента (мм)        |
| print_duration      | duration  | Расчётное время печати                |
| nozzle_temp_c       | int       | Температура сопла                     |
| bed_temp_c          | int       | Температура стола                     |
| slicer              | string    | Слайсер                               |
| notes               | string    | Заметки                               |
| printed_at          | timestamp | Дата печати                           |
| created_at          | timestamp | Дата создания записи                  |

### DryingSession (Сушка)

| Поле           | Тип       | Описание                          |
|----------------|-----------|-----------------------------------|
| id             | UUID      | Уникальный идентификатор          |
| spool_id       | UUID      | FK на катушку                     |
| temperature_c  | int       | Температура сушки (°C)            |
| duration_hours | float64   | Длительность (часы)               |
| notes          | string    | Заметки                           |
| dried_at       | timestamp | Дата сушки                        |
| created_at     | timestamp | Дата создания записи              |

### DryingProfile (Профиль сушки)

| Поле              | Тип     | Описание                              |
|-------------------|---------|---------------------------------------|
| material          | string  | Тип материала                         |
| temperature_c     | int     | Рекомендуемая температура (°C)        |
| duration_hours    | float64 | Рекомендуемая длительность (часы)     |
| max_days_no_dry   | int     | Макс. дней без сушки до предупреждения|

## 6. Интерфейс (UI)

### Основные экраны

1. **Дашборд** — сводная статистика, предупреждения о сушке.
2. **Катушки** — список катушек, добавление/редактирование, остатки.
3. **Новая печать** — импорт G-code, выбор катушки, указание статуса.
4. **История печатей** — таблица с фильтрами.
5. **Сушка** — журнал сушки, рекомендации.
6. **Настройки** — пути, единицы измерения, профили сушки.

### Навигация

- Боковая панель (sidebar) с иконками для переключения между экранами.
- GTK4 `Adw.ApplicationWindow` с `Adw.NavigationSplitView`.
